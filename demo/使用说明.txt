 旦行 · 辅导员职业发展数据平台 · 演示包
 使用说明（零技术基础 · Mac / Windows 通用）
==============================================

【准备工作：只需安装一次】

1. 安装 Docker Desktop
   - Mac：打开 https://www.docker.com/products/docker-desktop/ 下载 Mac 版（Apple 芯片选 Apple Silicon，Intel 芯片选 Intel）
   - Windows：同一网址下载 Windows 版，安装时保持默认选项（需要开启 WSL2，安装程序会自动处理）
   - 安装后启动 Docker Desktop，等右下角/菜单栏的鲸鱼图标静止，表示启动完成
   - 注意：首次运行需要联网（下载约 1GB 镜像和依赖）
   - 电脑内存建议 8GB 以上

2. 解压本演示包
   - 解压后得到一个文件夹，里面有启动脚本、配置和程序代码，不要单独移动里面的文件

【启动演示】

- Mac：双击「启动-Mac.command」（如提示"无法打开"，在文件上右键 → 打开）
- Windows：双击「启动-Windows.bat」

首次启动会自动构建和初始化（约 10-25 分钟，取决于网速），
请保持窗口打开耐心等待。完成后会自动打开浏览器访问平台。

之后每次启动只需 1-3 分钟。

【停止演示】

- Mac：双击「停止-Mac.command」
- Windows：双击「停止-Windows.bat」
数据会保留，下次启动继续使用。

【常见问题】

Q: 双击脚本闪退？
A: Mac 请在文件上右键 → 打开；Windows 请确认 Docker Desktop 已在运行。

Q: 打不开 localhost:8080？
A: 确认启动窗口里没有报错；等待 1-2 分钟后手动在浏览器访问 http://localhost:8080

Q: 想完全清空数据重来？
A: 停止后执行：docker compose down -v 再重新启动（会重新初始化演示数据）
