## 验证环境和边界

- 本环境无 Docker，原生 PostgreSQL 无法以可用非 root 身份启动。因此接口联调使用 **PGlite PostgreSQL WASM 引擎 + PostgreSQL JDBC + 真正的 Redis 7.4.11 服务**。先在测试数据库执行完整 SQL，再启动应用；该联调环境关闭 Flyway。生产配置仍是 PostgreSQL 16 和 Flyway，未被测试替身替换。
- PGlite 环境不等价于正式 PostgreSQL 集群。Docker Compose 的全量镜像构建、Flyway 在 PostgreSQL 16 上的首次启动、并发和重启恢复需要部署后验收。
- 前端使用 DOM 环境运行实际生产 JS，并连接真实 Java API；未完成桌面浏览器 / 手机浏览器的视觉截图验收。
- MinIO 源码已成功编译，但当前运行环境限制网络接口枚举，无法启动其真实服务。附件服务通过单元测试验证；**MinIO 上传、下载、私有桶访问和实际持久化尚未完成实机联调**。
- 助手功能及 Spring AI 集成现已移除；以上助手相关验证数据属于移除前的历史记录。

## 部署后接口验收

完整启动后，在测试数据库执行：

```bash
export SMOKE_ADMIN_PASSWORD='你的管理员密码'
python3 scripts/smoke-test.py --base-url http://localhost:8080
```

PowerShell：

```powershell
$env:SMOKE_ADMIN_PASSWORD='你的管理员密码'
python scripts/smoke-test.py --base-url http://localhost:8080
```

脚本默认验证真实附件上传下载；仅当明确不测试文件服务时，才加 `--skip-files`。脚本检查管理员辅导员管理范围，使用两个尚未关联账号的辅导员画像创建隔离验收账号，并清理测试计划、日程、收藏和附件；验收账号及审计日志保留，便于排查。

建议再手动检查：

1. 浏览器刷新和后端重启后，已保存的计划与日程仍在。
2. 辅导员账号无法进入管理员接口，也不能下载其他账号的附件。
3. 手机宽度下五个底部入口、详情弹窗与日历横向滚动正常。
5. 首次导入完成后再次启动，资料总数仍为 567，不重复插入。

这些部署验收项未被标记为已完成。
